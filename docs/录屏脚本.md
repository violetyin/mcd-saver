# 录屏脚本（2 分钟版）

> 目标时长 1:55–2:05。旁白总共约 200 字，平均每条 15–25 字——**宁可少说，让画面自己讲**。
> 录之前先空跑一次，确认数字对得上再正式录。

## 录制前 30 秒

1. 服务在跑：`cd /d/1024-mcd-saver && node web/server.mjs`
2. 浏览器开 `http://127.0.0.1:4173/`，F11 全屏，缩放 100%，关掉其它标签
3. **别开 `.env`**，Token 会入镜
4. 录屏用 `Win + G` 就够

## 演示参数

2 人 · 预算 100 元 · 不选忌口 · 武汉/光谷 · 看热量勾上

参考数字（2026-10-24 实测，仅对照，以现场为准）：方案 1 实付 ¥27.80、人均 ¥13.90；同样两件分开单点 ¥47.00，省 ¥19.20。

## 被追问时才说的三句

- **省 19.2 怎么来的**：那套套餐里的两件，各自按单点再算一次，同商品同份数，47 减 27.8。
- **为什么先选门店**：券绑门店，`query-store-coupons` 必须带 storeCode。
- **会不会乱下单**：不会，`create-order` 只在用户点确认后调，创建的是待支付订单，随时可取消。
