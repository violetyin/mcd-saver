# 麦门省钱助手（mcd-saver）

**不是帮你点餐，是帮你把账户里已经付过钱的东西用掉。**

你有几张券、还有几张能领、多少积分已经过期——先把这些盘清楚，再决定今天这顿怎么点。每一分钱都来自麦当劳 MCP 的 `calculate-price` 实时计算，不是把标价加起来估的。

> 本项目为「1024 超能 Coding 周末」用餐赛道 + 麦当劳程序员创意开发大赛参赛作品，由作者独立开发，非麦当劳官方产品。餐品、价格、优惠以麦当劳官方渠道实时结果为准。

---

## 它解决什么问题

在麦当劳点餐，钱通常不是花在「选哪个汉堡」上，而是漏在这几处：

- 账户里有张「麦辣鸡腿堡三件套」券，46 元的套餐券后 22.9 元，但你没注意到它今天到期；
- 麦麦省里三张券一直没领，领了才能算进这一单；
- 积分攒着攒着就过期了——实测这个账户已经过期 1334 分；
- 一份 `随心配 1+1` 只要 13.9 元，同样两件东西分开单点要 23.5 元，差额全在你懒得算。

而**券只在特定门店、特定场景生效**，标价相加和实付价完全是两回事。

这个 Skill 把「盘账户 → 选门店 → 凑一单 → 算实付」变成一条命令。

## 真实效果（武汉光谷通信广场店，2026-10-24 实测）

```
💼 券资产：持有 3 张｜麦麦省可领未领 0 张
   · 积分：可用 74｜已过期 1334.3｜本月将过期 27.6
📊 参考点法（牛肉堡单品精选×2 + 灰焰圆筒×2 + 纯悦×2）：¥53.00

方案 1｜精选超值随心配 ×2
   ── 实付 ¥27.80，人均 ¥13.90
   · 套餐默认含：那么大鸡排（椒盐风味） + 阳光柠檬红茶中杯
   ── 同样这些吃的分开单点 ¥47.00，套餐省 ¥19.20（41%）
   · 约 1004 大卡 / 蛋白质 48g / 脂肪 42g

方案 2｜人气经典随心配 ×2
   ── 实付 ¥29.80，人均 ¥14.90
   ── 同样这些吃的分开单点 ¥65.00，套餐省 ¥35.20（54%）
   · 约 858 大卡 / 蛋白质 54g / 脂肪 44g（2 项中 1 项可查，未含 可乐麦炫酷）

方案 3｜用券：麦辣鸡腿堡三件套 + 牛肉堡单品精选×1
   · 麦辣鸡腿堡3件套 ×1   ¥22.90（原价 ¥46.00）
   ── 实付 ¥36.90（标价 ¥60.00），券省 ¥23.10（39%）
```

一次跑完真实调用麦当劳 MCP **27 次**，覆盖门店、账户券资产、菜单、券、算价、套餐构成、营养。

两个细节值得单独说：

- **「省 41%」是怎么来的**：把那套套餐默认包含的两件单品，各自按单点再算一次价（同商品、同份数），47 元是分开买的价格，27.8 是套餐价。不拿不同餐品硬比。
- **「3 项中 2 项可查」不是含糊**：营养表只收录常见餐品，麦炫酷系列一条都没有。缺哪项就写出来，不拿部分数据冒充全量。

## 安装

```bash
git clone <本仓库地址>
cd mcd-saver
cp .env.example .env      # 填入你的 MCP Token
```

`.env` 里写：

```
MCD_MCP_TOKEN=你的Token
MCD_CITY=北京
MCD_KEYWORD=国贸
```

Token 在 https://open.mcd.cn/mcp 用手机号登录 → 右上角「控制台」→「激活」→ 复制。

**不需要 `npm install`**：全部零依赖，Node.js ≥ 18 即可。

## 使用

```bash
# 两个人 100 块，带营养信息
node src/cli.mjs --people 2 --budget 100 --nutrition

# 一个人 30 块，不吃辣，指定商圈
node src/cli.mjs -p 1 -b 30 --avoid 辣 --city 北京 --keyword 国贸

# 知道门店编号，直接跳过搜索
node src/cli.mjs -p 3 -b 150 --store 1950564

# 结构化输出，便于接网页 / 机器人
node src/cli.mjs -p 2 -b 100 --json
```

| 参数 | 含义 |
|---|---|
| `-p, --people` | 用餐人数 |
| `-b, --budget` | 预算（元）；加 `--per-person` 变成人均预算 |
| `--avoid` | 忌口：辣 / 牛肉 / 鸡肉 / 猪肉 / 鱼 / 咖啡 / 冰 |
| `--city` `-k, --keyword` | 门店搜索范围与商圈关键词 |
| `--store` | 直接指定 storeCode |
| `--nutrition` | 附带热量 / 蛋白质 / 脂肪 |
| `--json` | 输出 JSON |

## 网页版（路演/录屏用）

```bash
node web/server.mjs        # 打开 http://127.0.0.1:4173
```

点选人数、预算、忌口，直接出三套方案卡片。Token 只在服务端，前端拿不到，也不需要额外依赖。

## 作为 WorkBuddy Skill 使用

把整个仓库目录放进 `~/.workbuddy/skills/mcd-saver/`，之后在 WorkBuddy 里直接说：

> 我们两个人，预算 100，不吃辣，帮我点麦当劳

Skill 会自动带上门店、预算、忌口去跑引擎。详见 [SKILL.md](./SKILL.md)。

也支持走 WorkBuddy 连接器直连：在【连接器】→【自定义连接器】里配

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": { "Authorization": "Bearer YOUR_MCP_TOKEN" }
    }
  }
}
```

## 目标用户

1. **一个人吃午饭的上班族**：预算固定，想吃饱又不想多花钱。
2. **两三个同事/朋友拼单**：人数一多，套餐和多人餐的差价就拉开了。
3. **手里攒了一堆券不知道怎么用的人**：券按门店生效，最容易白躺过期。
4. **想控制热量的人**：`--nutrition` 会把套餐里真实餐品的热量加起来。

## 工作原理

1. `query-nearby-stores` 定门店（到店自取 `beType=1`，不传 `beCode`）。
2. `query-my-coupons` / `available-coupons` / `query-my-account` 盘账户：持券、可领券、积分过期。
3. `query-meals` 拿当店菜单，按「多人餐 / 单人套餐 / 主食 / 小食 / 饮品」分桶。
4. `query-store-coupons` 拿本店可用的券——**换门店券就变，所以必须先定门店**。
5. 用模板生成候选组合（券 / 单人套餐 / 多人餐 / 自由搭配 / 完整一套），控制在 18 个以内；券 ≥2 张时追加拆单方案。
6. 每个候选调 `calculate-price` 算实付，剔除异常返回。
7. 前三个方案补 `query-meal-detail`，把套餐里的单品展开，再用**同商品同份数**的单价算一次，得到「分开买要多少钱」。
8. `--nutrition` 时匹配营养表；匹配不全就把缺口写出来，不整条丢掉。

细节与踩过的坑见 [MCP_INTEGRATION.md](./MCP_INTEGRATION.md)。

## 边界

- **下单是可选的一步，且默认不付钱**：选定方案后可以真的创建订单，`create-order` 会返回 `payH5Url`，付不付由你自己决定；任何一笔订单都能用 `cancel-order` 立刻取消。本工具不会自动跳支付、不会保存你的支付信息。
- **不为未支付的订单负责**：订单创建后会在麦当劳账号里留痕（未支付可取消），长期不取消可能影响账号，界面上一键取消就是为这个准备的。
- **不承诺绝对最低价**：枚举的是有限候选，结论是「在试过的组合里最划算」。
- **忌口是启发式**：按餐品名匹配，套餐内部构成仍要看门店当日在售。
